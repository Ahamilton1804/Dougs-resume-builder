# Doug’s Career Workspace

This private repository is the working record for Doug Gardner’s career transition after thirteen years at AFP. It exists to recover the work, judgment, and results that matter for his next role, then turn the strongest evidence into a resume, LinkedIn profile, interview stories, and a clear account of the work he wants to pursue.

The first task is factual recovery. The project will capture what Doug can honestly say he did, how each claim is supported, what remains an informed account from experience, and what is only a lead from a chat, project, profile, or recollection. The resume is an output of that record. It is not the record itself.

## Working method

The career map establishes the sequence of roles, changes in mandate, and pivotal chapters. The evidence ledger holds the claim-level record. Each entry distinguishes Doug’s personal contribution from team activity, records the strongest available evidence basis, and identifies anything that cannot be used externally.

The skills support the work without replacing judgment. The professional-evidence skill drives the evidence interview, claim testing, and targeting. Doug’s judgment profile helps surface patterns in how he solves problems, where he may understate a contribution, and how to prepare a concise spoken case. Neither skill proves a career claim. Specific work and honest recollection do that.

## Current work

The workspace has the evidence structures and two reusable skills. No role chronology or accomplishment entries have been added yet. We will begin with the current AI-strategy role, recover the strongest recent work, and work backward through the career transitions that explain growing scope.

## Boundaries

Keep the repository private. Store only distilled, externally safe material. Do not add raw AFP documents, unreviewed Notion exports, internal metrics, confidential chat transcripts, credentials, or copied work files. GitHub provides cross-machine version history; this checkout stays outside OneDrive, Dropbox, and similar sync folders.

## Working with Claude

Install `claude-packages/professional-evidence-builder.skill` in Claude’s Skills settings. It uses the same evidence ledger and career-interview discipline as the Codex version. When moving work between assistants, use the handoff packet in the skill and keep the evidence ledger as the shared record.
